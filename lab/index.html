본문 추출이 까다로운 페이지 모음입니다.

  • 자바스크립트로만 그려지는 글
  • 본문이 iframe 안에 있는 글
  • 숨은 글과 떠 있는 창이 섞인 글
  • 페이지를 찾을 수 없습니다
  • 한강 반포에서 동작까지 걷기 (복사본)
  • 색인하지 말라고 표시한 글
  • Daum 추출 지정 class를 붙인 글
  • 표로 틀을 짠 옛날식 페이지
  • 날짜가 여러 개 나오는 글
  • 두 줄짜리 글
  • 다른 주소로 옮긴 글 (meta refresh)
