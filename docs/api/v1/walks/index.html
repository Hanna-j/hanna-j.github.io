코스 목록 조회

등록된 산책 코스 목록을 거리순으로 돌려줍니다.

요청

GET /api/v1/walks?min_km=1&max_km=5
Authorization: Bearer {토큰}

참고 토큰은 하루 1,000번까지 쓸 수 있습니다.

파라미터

이름형식설명
min_km숫자최소 거리 (기본 0)
max_km숫자최대 거리 (기본 제한 없음)

응답

{
  "walks": [
    {"id": 1, "name": "반포~동작", "km": 3.0},
    {"id": 2, "name": "낙산 성곽길", "km": 2.0}
  ]
}

주의 v1은 2027년 6월에 종료됩니다. v2로 옮겨 주세요.
